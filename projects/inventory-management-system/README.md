# Inventory Management System

## Project Overview

The Inventory Management System is a web-based application designed to manage products, stock, suppliers, customers, purchases, and inventory information efficiently.

## Technologies Used

- Python
- Django
- MySQL
- HTML
- CSS
- JavaScript

## Features

- Product management
- Inventory and stock management
- Supplier management
- Customer management
- Purchase management
- Search and reporting
- Dashboard with inventory information

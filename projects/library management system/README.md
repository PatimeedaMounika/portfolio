# Library Management System

## Project Overview

The Library Management System is a web-based application developed using Django to manage books, students/members, book issue and return records, and library information efficiently.

## Technologies Used

- Python
- Django
- MySQL
- HTML
- CSS
- JavaScript

## Features

- Book management
- Student/member management
- Book issue and return management
- Search books and members
- Track issued and returned books
- Database integration
- User-friendly dashboard
